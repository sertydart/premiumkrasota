Необязательная папка со шрифтом Montserrat (чтобы шрифт был одинаковым у всех, без интернета и VPN).
Скачайте Montserrat с кириллицей и положите сюда файлы с точно такими именами:
Montserrat-ExtraLight.woff2  Montserrat-Light.woff2  Montserrat-Regular.woff2  Montserrat-Medium.woff2
Пока файлов нет, сайт использует Segoe UI / Helvetica / Arial. Это работает полностью без интернета.
